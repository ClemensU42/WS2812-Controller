# WS2812 LED Controller

The WS2812 LED Controller is a control board used to control RGB-LED Matrices and LED-Strips based on WS2812 LEDs. It uses a USB-Interface, being able to be controlled by any USB-Host. Besides acting as the controller, it also provides several GPIO lines that can be read from and written to.

## Specs

- up to 8 LED-Lines
- 8 GPIO lines
- STM32F103RET6 Microcontroller
- On-board 3.3V regulator
- Each LED-Line running at 800Kbps
- USB2.0 Full-Speed via a USB-C connection
